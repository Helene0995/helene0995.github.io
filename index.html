About

My work usually starts with raw technical data. I connect to a machine or a remote server, collect and clean what it sends, store it in the right database, and then build an interface that lets a person understand it and act on it quickly.

At Sylfen, a French clean-energy company, I worked across the whole path: planning meetings, Visio wireframes, Node.js and Python code, integration testing, deployment, operator training and ongoing maintenance. I also worked on the PLC side in Beckhoff TwinCAT 3, managing the tags that connect the equipment to the software. That gave me a habit I bring to every project: build for the person who will use the screen every day.

I now live in Illinois and I am looking for my next role in industrial automation, energy, or IIoT software, where my work connects real equipment to the people who operate it.

SYL-SUP · Full-stack web

Industrial Supervision Platform

Sylfen, France
2020 – 2024

A modular web application, hosted on internal servers, that lets operators monitor live equipment values and control an energy system from the browser.

The challenge

  • Plant operators needed one reliable screen to watch and steer a complex industrial process.
  • Data came from industrial controllers in real time, not from a typical web API.

What I did

  • Joined architecture and technology-choice meetings and helped plan the schedule.
  • Designed module screens in Visio, then built them in Node.js, Express and EJS.
  • Streamed live values to the browser with Socket.io over OPC UA data.
  • Wrote integration tests, deployed, and trained operators.

Result

  • Became the daily tool operators used to supervise the system.
  • I maintained it through 2024, adding, updating and removing modules as the installation changed.

SYL-PV · Data & visualization

Solar Monitoring & Forecasting Dashboard

Sylfen, France
2022 – 2024

A Python dashboard that tracks a client's photovoltaic production and compares it with power estimates built from weather forecasts.

Collect

  • Connected to the client's remote server by IP and read production data over Modbus TCP/IP.
  • Stored it in InfluxDB, a time-series database, with a daily archive on our internal server.

Clean & compute

  • Used pandas to remove duplicates and impossible values so every chart could be trusted.
  • Brought in cloud-cover and temperature forecasts to estimate expected solar output.

Visualize & ship

  • Built a Streamlit dashboard with a sidebar calendar and a selector for the data to display.
  • Used multi-scale line charts so very different values read on one screen.
  • Deployed internally and refined it from user feedback.

SYL-BAT · Backend & real-time

Battery Charge-Cycle Test Software

Sylfen, France
2024

Backend software that tested charge and discharge cycles so the team could validate which battery type to use in its energy system.

Connect

Store

  • Processed the readings and stored each test cycle in PostgreSQL for later analysis.

Display
